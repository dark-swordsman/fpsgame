# PHILOSOPHY

How I want to go about working on this project and why.

The first iteration of this project was semi-successful. Some things worked as expected and I was making real progress.

The problem was that I didn't write most of the code myself, if at all. It was all Claude. As such, I didn't have any attachment to the code so I barely understood how it actually worked, even if on the surface I understood what it was doing.

So, as a result, there are rules now available in [RULES.md](RULES.md) that describe what is and is not allowed in this repository.

## Core Premise

This is a project not only for me to make a game I always wanted to make, but to finally develop my game development skills.

I have some experience generally and have enough to do basic things, but I never really went through the whole process of shipping and maintaining a complex game. I want to get really good at this.

I need to work on the code myself and make all the creative/hard decisions without relying on AI. I want to get better at this.
