# Persistence & Death

## Default Model

- DayZ-style: die and lose everything carried on your person
- Bunker stash is safe — gear stored there persists across deaths
- Respawn at default shore locations or at your bunker (bed spawn point)

## Server Configurability

All of this is configurable by server operators. The default is a starting point, not a mandate. Communities can define their own rules (full loot, safe zones, custom respawn logic) via the mod/config system.
