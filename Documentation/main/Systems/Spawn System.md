# Spawn System

## Principles

- Balance — world should feel neither empty nor cluttered
- Density — varies by zone type (military, civilian, industrial)
- Rarity — tiered loot, scarcer high-value items
- Context-based spawns — items appear in places that make sense (guns in military bases, food in kitchens)

## Applies To

- Items / loot
- Vehicles
- AI / enemies
- Events / anomalies
