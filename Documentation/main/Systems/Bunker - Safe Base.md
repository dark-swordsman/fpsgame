# Bunker / Safe Base

## Concept

Personal safe space for each player — somewhere between Tarkov's hideout (permanent, private) and DayZ's freeform bases (exposed, raidable).

## Goals

- Every player has access to the same baseline level of security
- Prevents the "big clan dominates solo players indefinitely" problem from DayZ
- You should have somewhere that your gear is reasonably safe
- Not about making raiding impossible — about making the game not feel hopeless for smaller groups

## Open Questions

- How persistent is the bunker across server sessions?
- Can bunkers be raided at all, or are they truly safe?
- Is the bunker entrance in the world (like the north star scene) or instanced?
- Upgradeable over time (Tarkov hideout style)?

## Notes

The north star scene features a bunker entrance — this is a literal and symbolic anchor for the feature.
