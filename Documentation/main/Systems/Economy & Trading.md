# Economy & Trading

## Systems

- AI traders in the world (STALKER / Tarkov-style)
- Player-to-player trading
- Global currency / market system

## Dynamic Market

Item values fluctuate over time via a lightweight market simulation:
- Mimics basic real market conditions — supply, demand, scarcity
- Not deeply simulated; enough that prices feel alive and player behavior can move them
- Examples: high consumption of a certain ammo type drives price up; an event flooding a zone with loot drives local values down
- Updates on some interval (per server tick, daily cycle, etc.) — TBD

## Balance Notes

- Ammo scarcity is intentional — unlike DayZ default servers
- Should feel tense, not punishing; risk should have proportional reward
- See [[Inventory]] for how items flow
